# Origins and reuse

The gearbox is an original SynthCrew reference project. The private CAD agent authored the engineering work from a project brief and an input-side service decision. The assembly uses FreeCAD's installed PartDesign involute generator. No downloaded gearbox geometry, vendor bearing model, product application source, CAD engine or toolchain is included.

The bearings, threads and hardware in this example are design geometry, not manufacturer-certified parts. The reference model carries no load rating. See the model notes for the geometry that was actually checked.

The section PDF embeds DejaVu Sans font subsets. The original DejaVu and Bitstream Vera notices accompany the project in FONT-NOTICES.txt. The drawing frame and service illustration are project outputs, not downloaded CAD components.
